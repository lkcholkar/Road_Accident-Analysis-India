# Road Accident Analysis in India

## Project Overview
This project uses Python to explore road accident data across Indian States and Union Territories. It focuses on understanding year-wise trends and comparing reported accident figures through data analysis and visualization.

## Objectives
- Analyze road accident data.
- Compare accident figures across years.
- Explore State/UT-wise accident statistics.
- Present findings using visualizations.

## Tools and Technologies
- Python
- Pandas
- Matplotlib
- Seaborn

## Project Files
- `road_accidents_analysis.py` — Python analysis script
- `RA2019_A2.csv` — Dataset used for analysis
- `road.png` — Road accident visualization
- `top_10_states.png` — Top 10 States/UTs visualization

## How to Run
1. Install Python.
2. Install the required libraries:
   `pip install pandas matplotlib seaborn`
3. Keep the dataset in the same folder as the Python script.
4. Run:
   `python road_accidents_analysis.py`

## Note
This project was created for learning and exploratory data analysis. Findings depend on the dataset used.
